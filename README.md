## 这是什么

一个可交互的产品原型，演示「识别 → 冷静期 → 隐私最小化联动」的完整反诈链路。

打开页面后：

1. 点一个示例话术（如「刷单返利」）→ 点「开始检测」。
2. 看判定结果：风险分、诈骗类型标签、命中的行为信号、以及对方**下一步会说什么**的剧本预告。
3. 在三道自检题里点任意一个「是」→ 触发高风险流程。
4. 看隐私最小化联动：发给室友与辅导员的通知里**不含金额、不含聊天内容**，且 60 秒内可撤回。

## 为什么做这个

2025 年湖北省电诈受骗人中，16—35 岁青年群体占 **45.86%**，为各年龄段最高；其中“00 后”占 **21.5%**，较上年上升 **6.37 个百分点**。刷单返利（25.01%）、虚假网络投资理财（15.24%）、虚假购物服务（14.14%）三类合计占全部案件近 **55%**。

这些案件的共同点是：转账动作发生在**深夜、陌生对手方、金额递增**的窗口里——而现有的反诈提醒大多发生在转账完成之后。青盾要做的，是把防线推进到**按下确认之前的 15 秒**。

## 技术说明

- 纯静态单文件：`index.html`，零依赖、不联网、不收集任何数据。
- 本仓库中的判定逻辑是**可解释的规则引擎**，用于向评委演示完整链路。
- 正式方案中的识别引擎为：大模型语义判断 + 轻量分类模型 + 规则引擎兜底。

页面内所有案例为公开通报手法整理的**典型化**场景，不涉及任何真实个人隐私；原型不采集、不上传、不存储任何用户输入。
